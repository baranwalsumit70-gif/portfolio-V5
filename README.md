# Sumit Baranwal · Portfolio

Static site. No build step.

## Deploy on GitHub Pages
1. Create a repo (e.g. `portfolio`) and upload everything inside this folder to the repo root, including `.nojekyll` (it keeps the `_ds` folder from being ignored).
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
3. Site goes live at `https://<username>.github.io/<repo>/` in 1–2 minutes.

`index.html` is the portfolio home. Case studies and prototypes are the `.dc.html` files.
